# Versión 4.6

- El botón Escanear abre un selector con cámara y documentos PDF/imagen.
- Si se usa cámara, guarda la foto temporalmente y la adjunta al WhatsApp.
- Si se selecciona PDF/imagen, se adjunta al WhatsApp.
- Nota: Android no tiene un intento universal obligatorio para escáner PDF; si hay una app de escaneo instalada y registrada, aparecerá como opción. Si no, aparece la cámara.
